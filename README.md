# AI_Trade_Projekt - DAX RL Documentation (Cleaned Version)

This repository contains the cleaned and structurally improved documentation for the DAX RL trading agent project.

## Overview

Reinforcement learning agent for intraday DAX futures (FDAX), built on **CleanRL** with **dual-rate policy architecture**, frozen Auxiliary Future Prediction (AFP), and behavior cloning warmup.

**Long-term targets:** +35% annual return, max 10% annual drawdown.
